# elden-ring-web
艾尔登法环主题全栈网站，Node.js+Express后端，MySQL存储，云服务器部署

##  项目介绍
基于Express搭建的全栈网页项目，以艾尔登法环为主题，包含首页、交界地地图、角色介绍、用户登录注册功能。
后端提供接口，使用JWT做登录鉴权，密码采用bcrypt加盐哈希加密，部署在腾讯云服务器，PM2进程守护保证服务持续运行。

##  技术栈
- 后端：Node.js、Express
- 数据库：MySQL2
- 身份鉴权：JWT
- 密码加密：bcryptjs
- 跨域处理：cors
- 部署：腾讯云服务器 + PM2

##  功能模块
1. 用户模块：注册、登录。密码加盐加密存储；每次请求校验JWT，并且查询数据库判断用户是否存在，修复了旧Token仍可访问的安全漏洞
2. 页面模块：首页、交界地地图、角色介绍页面
3. 静态资源：html页面、图片资源
4. 服务托管：PM2守护进程，服务器重启自动拉起项目
